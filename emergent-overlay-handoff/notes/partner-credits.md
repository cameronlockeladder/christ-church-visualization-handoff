# Partner Credits

These are the project partner credits for the Christ Church Oak Brook scope/timeline microsite.

Use the logo assets in `assets/partner-logos/` and keep the acknowledgement language plain. Do not make this section feel like advertising.

## Credits

- Crane and forklift provided by Imperial Crane and BJ Bohne, a member of the church.
- All material provided by Bone Roofing Supply, long-standing members of the church.
- Prime Scaffold is providing all scaffolding equipment and crews.
- Great Lakes Kwik Space is providing the storage container for material staging.
- Porta Potty Dogs is providing the porta potty.

## Implementation Notes

- Use `imperial-crane.png` for the Imperial Crane / BJ Bohne line. BJ Bohne is an individual contact, not a separate logo.
- Bone Roofing Supply's official logo file is white on transparent background. Place it on a darker warm neutral tile or band so it is readable.
- Prime Scaffold's official site only exposed a JPG logo. The repo contains a PNG conversion so the web build can stay within PNG/WebP logo formats.
- Keep logo treatment quiet and even. The purpose is to identify project contributors, not to create a sponsor wall.
